# AI机甲麦轮车拓展包

本拓展包提供 AI机甲麦轮车的图形化积木和 Python 代码生成配置。

## 安装

请从产品拓展仓库的 Releases 页面下载 `.sbext` 文件。在软件中打开“拓展库”，进入“用户拓展”后使用本地导入功能安装。

不要下载 GitHub 自动生成的 Source code 压缩包，它不是可安装的拓展包。

## 版本

拓展包使用语义化版本号。升级前请查看对应 Release 的更新说明和兼容信息。

## 文件说明

- `manifest.json`：产品名称、版本和兼容信息。
- `blocks.json`：积木分类、参数和菜单。
- `generator/python.json`：积木对应的 Python 代码生成规则。
