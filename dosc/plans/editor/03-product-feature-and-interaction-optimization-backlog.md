# 产品功能与交互优化需求清单

> 记录日期：2026-08-20
> 当前状态：需求已记录，尚未进入实现
> 范围：桌面项目生命周期、SB3 导入、Python 代码区、串口上传、扩展库、设置与诊断

## 目标

当前项目已经跑通 Scratch 编辑、Python 生成与运行、串口上传和产品扩展库等主链路。下一阶段需要补齐恢复、诊断、失败处理和版本管理，让功能从“可以演示”进入“可以长期使用”。

本文统一记录本轮调研发现的 10 项需求。实现时仍应拆成独立任务，每次只处理一个可验收子项。

## 1. 项目打开、最近项目和未保存保护

### 当前依据

- 首页已有“打开项目”入口，但当前处于禁用状态。
- 桌面 Tab 数据包含 `dirty` 字段，壳页面也能显示标记，但尚未形成编辑器到主进程的状态更新链路。
- 关闭 Tab 会直接释放视图和 Python/PTY 进程，没有保存确认流程。

### 目标功能

- 从首页通过原生文件对话框打开 `.sb3`。
- 记录最近项目路径、名称、模式和最近打开时间。
- 编辑后显示未保存标记，保存成功后清除标记。
- 关闭 Tab、关闭窗口或切换项目时提示保存、放弃或取消。
- 启动后可恢复上次打开的 Tab；恢复失败时回到首页并显示原因。

### 验收边界

- 取消打开或关闭操作不能改变当前项目。
- 最近项目文件不存在时允许从列表移除，不能导致首页报错。
- 每个 Tab 独立维护路径、模式和 dirty 状态。
- 关闭 Tab 后 Python、PTY 和串口资源必须释放。

## 2. SB3 事务式导入和失败恢复

### 当前依据

项目已修复旧机器人残留、重复挂载和拖入 SB3 的基础问题，但加载流程仍需要更明确的原子边界。

### 目标功能

- 拖入或选择 SB3 后先解析和校验，再替换当前项目。
- 加载过程显示“解析、清理旧项目、恢复扩展、生成代码”阶段。
- 只有新项目完整加载成功后才提交机器人和扩展状态。
- 加载失败时保留或恢复原项目，不留下半加载状态。
- 加载前识别项目使用的机器人、模块和扩展版本。

### 验收边界

- 无效、损坏或不兼容 SB3 不清空当前工作区。
- 新作品、菜单加载和拖拽加载走同一套清理规则。
- 同一时间只能挂载一个主产品；失败后不能残留重复扩展。
- Python 代码必须基于最终成功加载的工作区重新生成。

## 3. 串口上传可靠性

### 当前依据

现有实现已经支持 Raw REPL、阶段进度、动态分块和设备端字节数校验。因暂无测试机器，当前仍标记为未人工检验。

### 目标功能

- 增加总超时、阶段超时、取消和有限重试。
- 监听设备拔线并恢复连接状态。
- 先写临时文件，校验成功后再替换 `main.py`。
- 探测 Raw-Paste 能力，不支持时回退 Raw REPL。
- 记录设备型号、固件能力、上传耗时、字节数和失败阶段。
- 提供模拟串口适配器，在无真机时覆盖协议状态机。

### 验收边界

- 取消、超时或拔线后释放 reader/writer lock，并允许重新连接。
- 上传失败不能破坏设备上原有的 `main.py`。
- 只有设备端校验通过后才能显示成功。
- 真机验收需覆盖中文代码、大文件、设备忙、重复上传和多串口。

## 4. Python 编辑器式代码体验

### 当前依据

代码区目前使用只读文本区域，可以加载、保存、运行和上传 Python，但缺少编辑器式的语法层次和定位能力。

### 目标功能

- 第一阶段增加 Python 关键字、字符串、注释、数字和运算符高亮。
- 后续评估行号、搜索、错误行定位和“查看/编辑”模式切换。
- 明确显示代码来源：积木生成、文件加载或手工编辑。
- 代码与积木不一致时，在运行和上传区域显示状态。
- 手工编辑模式不反向转换为积木。

### 验收边界

- 高亮不能改变原始文本、复制内容、缩进和换行。
- 多行字符串、中文注释和大文件必须稳定展示。
- 解析失败时回退普通文本，不阻塞加载、保存、运行和上传。
- 详细高亮规则见 `../python/05-network-source-python-load-and-serial-upload-requirements.md`。

## 5. 扩展版本锁定和更新管理

### 当前依据

扩展库已经支持内置包、远程包、缓存包、用户包、Gitee/GitHub 自动选源和 SHA256 校验，但项目尚未锁定实际使用版本。

### 目标功能

- 在项目中记录扩展 ID、版本、来源和 checksum。
- 加载项目时优先恢复指定版本，不静默升级。
- 显示当前版本、可更新版本和更新说明。
- 更新失败时继续使用已校验的旧版本。
- 校验扩展与主产品、固件和 Python 运行库的兼容关系。

### 验收边界

- 离线打开项目时优先使用匹配的已校验缓存。
- 指定版本不存在时明确提示用户选择回退版本。
- 扩展更新不能重复挂载主产品或改变现有积木连接。
- 卸载和删除操作必须区分当前项目状态与本地包文件。

## 6. 远程来源状态和手动切换

### 当前依据

远程目录已经按网络响应自动选择 Gitee 或 GitHub，并保留失败回退和短期缓存，但界面没有展示当前来源和选择原因。

### 目标功能

- 显示当前来源、最近响应耗时和最近失败原因。
- 提供“自动选择、优先 Gitee、优先 GitHub”三种策略。
- 提供重新测速操作，并显示测速中的状态。
- 自动模式保留失败回退和 SHA256 校验。

### 验收边界

- 手动策略只改变优先顺序，不能绕过备用来源和校验。
- 测速失败不能清除已校验缓存。
- 网络恢复后允许主动重新探测，不要求重启应用。

## 7. 串口工具栏交互优化

### 当前依据

Python 顶部工具栏已经提供端口、波特率、刷新、连接、断开和上传，但设备身份、连接阶段和失败原因主要依赖控制台文本。

### 目标功能

- 使用明确的刷新、连接、断开和上传图标，并提供 tooltip。
- 显示设备名称、端口、VID/PID、波特率和连接状态。
- 记住每个产品最近使用的端口和波特率。
- 上传时显示阶段、百分比、已传字节和取消入口。
- 设备忙、权限拒绝、串口占用和协议失败使用不同提示。

### 验收边界

- 不可执行的操作必须禁用，并解释禁用原因。
- 连接和上传过程中不能触发冲突操作。
- 拔线后按钮、端口列表和状态提示保持一致。

## 8. 设置能力完善

### 当前依据

设置菜单已经保留中英文和具体 px 字号，并使用品牌黄色子菜单。后续需要补充持久化、恢复和设备相关偏好。

### 目标功能

- 字号提供合法范围、实时预览和恢复默认值。
- 明确设置是全局生效还是按 Tab 生效。
- 增加默认串口波特率和远程来源策略。
- 增加离线缓存开关和缓存清理入口。
- 支持设置导入、导出和恢复默认。

### 验收边界

- 非法 px 值不能破坏布局。
- 重启应用后保留已确认设置。
- 清理缓存前显示影响范围，不能删除用户导入包。

## 9. 诊断与支持信息导出

### 当前依据

运行、串口和扩展失败信息分散在控制台、Redux 状态和 Electron 主进程日志中，现场问题难以一次收集完整上下文。

### 目标功能

- 提供只读诊断页面和“导出诊断信息”操作。
- 收集软件版本、系统版本、编辑器模式和项目名称。
- 收集扩展 ID、版本、来源和 checksum，不导出包正文。
- 收集远程来源、最近测速、串口设备信息和上传失败阶段。
- 收集 Python 运行方式、退出码和最近错误。

### 验收边界

- 默认隐藏用户代码、文件正文、访问令牌和敏感路径。
- 导出前显示将包含的数据类型。
- 无串口或无网络时诊断页仍能打开。

## 10. 积木资源和可访问性质量检查

### 当前依据

部分 C 型积木曾出现右下角图标错误。积木包数量持续增加后，仅靠人工查看难以及时发现资源路径、尺寸和对比度问题。

### 目标功能

- 构建或测试阶段检查 manifest 引用的图标和资源是否存在。
- 图标加载失败时显示统一占位图，不出现破损图像。
- 校验积木图标尺寸、透明区域和浅色/深色背景对比度。
- 图标按钮提供 tooltip、焦点样式和无障碍名称。
- 扩展库、设置、代码区和串口工具栏支持键盘导航。

### 验收边界

- 缺失资源在测试或构建阶段给出扩展 ID 和资源路径。
- 中文、英文和不同字号下，文字不遮挡图标或相邻控件。
- 鼠标、键盘和屏幕阅读器均能识别主要操作。

## 推荐实施顺序

1. 项目打开、最近项目、dirty 状态和关闭提醒。
2. SB3 事务式导入和失败恢复。
3. 串口取消、拔线恢复、重试和临时文件替换；先完成模拟测试，再做真机验收。
4. 扩展版本锁定、更新和离线恢复。
5. Python 语法高亮、代码来源提示和错误定位。
6. 远程来源、设置、诊断、图标和可访问性交互优化。

除串口协议最终验收外，其余需求都可以在没有测试机器时先实现自动化测试。串口相关功能完成代码测试后仍必须保留“未人工检验”状态，直到真实设备回归通过。
