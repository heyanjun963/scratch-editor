# 模块卡片状态与 aimech 内置快照评审记录

> 当前状态：AI机甲双驱车已加入 editor 内置快照；模块卡片支持准确区分主控兼容性、发布状态和添加状态。

## 本轮范围

- 将 `aimech-1.0.0.mpext` 加入内置包清单，离线环境可直接加载 40 个产品积木。
- 从模块目录移除调试用的 HTTP/DeepSeek 和 Python 基础积木卡片。
- 移除未添加卡片右上角的下载箭头，整张可用卡片仍可点击添加。
- 已添加模块显示“已添加”，点击该标记可移除模块。
- 区分“请先加载主产品”“待发布”和“当前主控不支持该模块”。

## 卡片状态

| 条件 | 卡片文案 | 交互 |
| - | - | - |
| 未加载主产品 | 请先加载主产品 | 不允许添加 |
| 当前主控支持，已有内置或远程包 | 可加载说明 | 点击卡片添加 |
| 当前主控支持，包尚未发布 | 待发布 | 不允许添加 |
| 当前主控不支持 | 当前主控不支持该模块 | 不允许添加 |
| 模块已添加 | 已添加 | 点击标记移除 |

WonderLens 和 WonderMind 属于五款 AI 机甲支持但尚未发布的模块。其他未进入当前产品支持清单的模块显示“不支持”，不再统一标为“待发布”。

## 人工验收

1. 无主控时进入模块扩展，确认卡片显示“请先加载主产品”。
2. 加载任一 AI 机甲，确认 WonderLens、WonderMind 显示“待发布”。
3. 确认 180° 舵机等未受当前产品支持的模块显示“当前主控不支持该模块”。
4. 确认 HTTP/DeepSeek、Python 基础积木不再出现，未添加卡片右上角为空。
5. 添加旋钮传感器，确认右上角显示“已添加”；点击该标记后，输入模块分类从工具箱移除。
6. 加载 AI机甲双驱车，确认无需远程下载即可显示产品积木。
