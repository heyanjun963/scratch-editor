# 2026-08-07 开发日志

> 今日完成动力、机械臂、输出和通信四个公共模块的首批内置包迁移，共 8 个分类、35 个积木；所有内容均可在 editor 本地离线调试，无需先发布远程版本。

## 内置公共模块迁移

| 扩展包 | 版本 | 分类 | 积木数 |
| - | - | - | -: |
| `actuator` | `1.1.0` | 总线舵机、IIC转PWM控制模块、风扇 | 9 |
| `xarm` | `1.1.0` | 机械臂、AI机甲串联机械臂、AI机甲连杆机械臂 | 12 |
| `display` | `1.0.0` | RGB模块 | 5 |
| `communication` | `1.0.0` | PS3手柄 | 9 |

所有包均以 Mind+ `.mpext` 保存到 editor 内置快照，并由项目解析器生成同步 manifest。运行时不依赖远程版本或独立产品仓库。

## 关键兼容与代码生成

- 总线舵机、IIC 转 PWM、风扇和两类非基础机械臂支持五款大型 AI 机甲与 `aidoggy`；`aidoggy` 风扇端口保持 C/D/E/F 覆盖。
- 基础机械臂仅 `aimech` 支持；RGB 仅五款大型 AI 机甲支持；`minihexa` 不支持本日新增的共享模块。
- 机械臂 ID 设置通过变量强制覆盖顺序保证用户值覆盖默认值。
- RGB 颜色参数在生成期转换为 `0xff,0x99,0x66`，不再把 `int("#ff9966"[...])` 留到设备运行时。
- PS3 模块保留 MAC 初始化、连接、LED、震动、按键、摇杆和 IMU 的 9 条旧 Python 调用。
- 旧 PS3 震动强度滑块在当前 VM 没有对应参数类型，暂以数值输入保留默认值和生成语义；通用数值滑块作为后续独立工作。

## 内置快照与模块卡片

- 注册 `actuator`、`xarm`、`display` 和 `communication` 的内置 manifest、离线压缩包、版本和 SHA256。
- 快照同步脚本可识别 editor 内置来源，后续独立产品仓库补齐作者源后可切回产品仓库资产。
- 模块卡片仍只声明硬件兼容和后备状态；当对应内置 manifest 存在时，库来源解析器自动显示为可添加。提交前 review 已移除通信模块单独硬编码的 `available`，保持与其余公共模块一致。
